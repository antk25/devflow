# /transcribe — созвон в текст, локально

Записи OBS лежат в `/mnt/c/Users/Anton/Videos/` с именами `ГГГГ-ММ-ДД ЧЧ-ММ-СС.mp4`.
Внешние сервисы исключены: `curl` заблокирован, а записи с заказчиком наружу не выгружаются.

## Шаги

1. **Файлы.** Взять из аргумента; без него — `ls` записей за нужную дату и показать список с
   длительностью (`ffprobe -v error -show_entries format=duration -of csv=p=0`).
2. **Словарь.** Собрать `--prompt` из терминов проекта: стек и продукты из `AGENTS.md`, имена
   ключевых сущностей, латиница как пишется в коде. Без словаря русская речь коверкает термины
   (OpenSearch → «опансию», WooCommerce → «вы комикс»).
3. **Запуск** — один процесс на все файлы, в фоне, если записей больше 10 минут:
   ```bash
   ~/.claude/skills/transcribe/transcribe --prompt "<словарь>" <скретчпад>/calls <файл.mp4>...
   ```
   `--lang en` для англоязычного созвона. Первый запуск ставит venv в `~/.cache/devflow/whisper`
   и качает модель (~3 ГБ), дальше — около 4x реального времени.
   **Два процесса одновременно не запускать** — модель занимает почти всю видеопамять.
4. **В vault.** Для каждого `.txt` — `<vault>/notes/<дата>-calls-transcripts/<ЧЧ-ММ-СС>.md`:
   ```yaml
   ---
   created: <сегодня>
   project: <проект>
   type: transcript
   source: <путь к .mp4>
   tags: [созвон, расшифровка]
   ---
   ```
   Заголовок `# Созвон <дата> <время>`, строка-предупреждение «локальная расшифровка, термины и
   номера тикетов на слух искажены — сверять с записью», затем текст с тайм-кодами.
5. **Разбор.** Отвечать на вопрос пользователя по расшифровке с тайм-кодами, а не пересказывать всё.
   Найденные решения — ссылкой из ТЗ или заметки на файл расшифровки.

## Кадры с экрана

Если в разговоре «вот эта страница», «эти категории», номера тикетов — звука мало, нужен экран:
```bash
ffmpeg -nostdin -v error -ss <сек> -i "<файл>.mp4" -frames:v 1 -q:v 3 <vault>/notes/<дата>-calls-transcripts/shots/<ЧЧ-ММ-СС>-<сек>.jpg
```
Кадр попал на загрузку страницы — взять соседний (±20 сек).

## Если сломалось

- `libcublas.so.12 is not found` — скрипт сам выставляет `LD_LIBRARY_PATH`; если venv собран
  вручную, пересоздать: `rm -rf ~/.cache/devflow/whisper`.
- Фоновый процесс не виден в `ps aux` (урезанный `/proc`) — проверять `ps -p <pid>`.
- Тихий звук и так выравнивается `loudnorm`; для замера громкости — `ffmpeg -af volumedetect` без `-v error`.
- Встречи с заказчиком пишет Notta Bot — там двуязычная расшифровка с говорящими; локальная нужна,
  когда доступа к Notta нет.
