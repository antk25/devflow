# /transcribe — созвон в текст, локально

Записи OBS лежат в `/mnt/c/Users/Anton/Videos/` с именами `ГГГГ-ММ-ДД ЧЧ-ММ-СС.mp4`.
Внешние сервисы исключены: `curl` заблокирован, а записи с заказчиком наружу не выгружаются.

## Шаги

1. **Файлы.** Взять из аргумента; без него — `ls` записей за нужную дату и показать список с
   длительностью (`ffprobe -v error -show_entries format=duration -of csv=p=0`).
1a. **Разведка по кадрам — до расшифровки.** Сетка кадр-в-минуту:
   ```bash
   ffmpeg -nostdin -v error -i "<файл>.mp4" -vf "fps=1/60,scale=480:-1,tile=4x4" -q:v 4 <скретчпад>/frames/grid-%02d.jpg
   ```
   По ней видно: сколько созвонов в записи (Meet или хадл, заголовок «Huddle in <канал>», лица),
   где показ экрана и чей. Границу между созвонами уточнить кадрами через 30 с.
1b. **Разные созвоны в одной записи — резать.** Если язык или участники меняются, вырезать
   звук по границе (`ffmpeg -t <сек>` / `-ss <сек>`, `-vn -c:a copy` в `.m4a`) и расшифровать
   каждую часть со своим `--lang` и словарём; один `--lang` на смешанную запись портит обе части.
   В итоговом файле тайм-коды второй части сдвинуть на смещение, чтобы совпадали с записью.
2. **Словарь.** Собрать `--prompt` из терминов проекта: стек и продукты из `AGENTS.md`, имена
   ключевых сущностей, латиница как пишется в коде. Без словаря русская речь коверкает термины
   (OpenSearch → «опансию», WooCommerce → «вы комикс»).
3. **Запуск** — один процесс на все файлы, в фоне, если записей больше 10 минут:
   ```bash
   ~/.claude/skills/transcribe/transcribe --prompt "<словарь>" <скретчпад>/calls <файл.mp4>...
   ```
   `--lang en` для англоязычного созвона. Первый запуск ставит venv в `~/.cache/devflow/whisper`
   и качает модель (~3 ГБ), дальше — около 4x реального времени.
   **Два процесса одновременно не запускать** — модель занимает почти всю видеопамять.
4. **Расшифровка — в общую папку, не в проект.** В одной записи OBS часто несколько созвонов,
   не все про проект. Для каждого `.txt` — `/mnt/f/notes_2/calls/<дата>/<ЧЧ-ММ-СС>.md`
   (`notes_2` — одно хранилище Obsidian, wikilinks в проекты работают):
   ```yaml
   ---
   created: <сегодня>
   type: transcript
   source: <путь к .mp4>
   tags: [созвон, расшифровка]
   ---
   ```
   Заголовок `# Созвон <дата> <время>`, строка-предупреждение «локальная расшифровка, термины и
   номера тикетов на слух искажены — сверять с записью», таблица созвонов внутри записи
   (время · хадл · проект · ссылка на разбор), затем текст с тайм-кодами. Хадлы и границы
   видны по кадрам (заголовок «Huddle in <канал>») и по смене темы.
5. **Разбор — по одному на созвон.** Созвон по проекту — `<vault>/notes/<дата>-call-<хадл>.md`
   с `project:` и ссылкой `[[calls/<дата>/<ЧЧ-ММ-СС>|…]]`; остальные — рядом с расшифровкой,
   `calls/<дата>/<ЧЧ-ММ-СС>-<хадл>.md`. Отвечать на вопрос пользователя с тайм-кодами, а не
   пересказывать всё. Решения — ссылкой из ТЗ или заметки на разбор.

## Кадры с экрана

Если в разговоре «вот эта страница», «эти категории», номера тикетов — звука мало, нужен экран:
```bash
ffmpeg -nostdin -v error -ss <сек> -i "<файл>.mp4" -frames:v 1 -q:v 3 /mnt/f/notes_2/calls/<дата>/shots/<ЧЧ-ММ-СС>-<сек>.jpg
```
Кадр попал на загрузку страницы — взять соседний (±20 сек).

## Если сломалось

- `libcublas.so.12 is not found` — скрипт сам выставляет `LD_LIBRARY_PATH`; если venv собран
  вручную, пересоздать: `rm -rf ~/.cache/devflow/whisper`.
- Фоновый процесс не виден в `ps aux` (урезанный `/proc`) — проверять `ps -p <pid>`.
- Тихий звук и так выравнивается `loudnorm`; для замера громкости — `ffmpeg -af volumedetect` без `-v error`.
