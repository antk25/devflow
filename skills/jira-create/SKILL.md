# /jira-create — завести задачу в Jira

Скрипт: `~/.config/devflow/integrations/jira-create.sh` (ставится `install.sh`, пишет в инстанс
`JIRA_PS_*` из `config.env`). Для инстанса `JIRA_*` (resolventa) — не использовать: там `tracker`,
запись вручную.

## Порядок

1. **Правила проекта.** Прочитать раздел `## Jira` в `AGENTS.md` проекта: ключ проекта, язык
   задачи, кто её видит, типичные эпики. Раздела нет — спросить ключ проекта у пользователя, не
   угадывать.
2. **Черновик.** Название и описание на языке из `AGENTS.md`. Если язык не русский — под текстом
   полный русский перевод, чтобы пользователь видел, что уйдёт. Если задачу видит заказчик —
   без имён файлов, классов, веток; внутренние детали — в vault.
3. **Поля.** Тип — `Task` по умолчанию (`Bug` для поломки); список типов —
   `jira-create.sh -P <KEY> --types`. Родитель `-p <KEY>-<n>` и метки `-l` — только если
   пользователь их назвал или они записаны в `AGENTS.md`.
4. **Файл описания** — в scratchpad, в wiki-разметке Jira, не в markdown:
   `h3. Заголовок`, `* пункт`, `# нумерованный`, `*жирный*`, `{{код}}`, `[текст|url]`.
5. **Dry run** — показать, что уйдёт:
   ```bash
   bash ~/.config/devflow/integrations/jira-create.sh -P <KEY> -s "<summary>" -d <file> [-t Task] [-p <KEY>-n] [-l label]
   ```
6. **Запись — только после явного «да / создавай»** на этот черновик. Согласие на прошлую
   задачу не переносится на следующую. Запуск с `--yes` стоит под ask-правилом
   (`settings.global.example.json`), Claude Code спросит подтверждение ещё раз.
   ```bash
   bash ~/.config/devflow/integrations/jira-create.sh -P <KEY> -s "<summary>" -d <file> ... --yes
   ```
   Скрипт печатает `<KEY>-<n> <url>` — отдать ссылку пользователю.
7. Если задача связана с ТЗ или заметкой в vault — дописать туда номер новой задачи.

## Чего не делать

- Не создавать задачу по собственной инициативе.
- Не повторять `--yes` после ошибки, не разобравшись: Jira могла создать задачу и ответить
  ошибкой. Сначала поиск: `jira-search.sh 'project = <KEY> AND summary ~ "<слова>" AND created >= -1d'`.
- Комментарии, смена статуса, учёт времени — скрипт этого не умеет; только веб-интерфейс.
