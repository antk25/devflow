# DevFlow — общие правила

<!-- devflow-shared: 1 -->

## Конвейер

- `/devflow` ведёт research → plan → implement через общий CLI `devflow`.
  Состояние, одобрения и результаты меняются только через CLI, не правкой SQLite или `.devflow/`.
- Исследование и план требуют явного одобрения пользователя в текущей сессии.
  Агент не одобряет собственные документы.
- Один запуск implement — ровно один шаг одобренного плана в свежем контексте.
  Нельзя выполнять следующий шаг в том же запуске.
- При `running` сначала изучить git status, diff, changelog и тесты; затем восстановить
  выполнение через finish/resume/interrupt по решению пользователя. Не запускать шаг повторно.
- AGENTS.md проекта задаёт стек, команды, соглашения, vault и формат коммита.
  Артефакты хранятся в прежнем vault: tz/, research/, plans/, changelog/, notes/.
- Все заметки писать по-русски; имена файлов остаются латинскими.

## Git

- Ассистент создаёт ветки, коммитит обычным git commit, проверяет HEAD и делает git pull.
  По запросу он может опубликовать текущую feature-ветку и открыть PR в базовую ветку.
  Фазовый implement не публикует результат: это ответственность драйвера или пользователя.
- Пуш в базовую/продовую ветку, main/master и слияние PR выполняет пользователь.
  Не использовать force push, удаление веток через push, gh api, gh pr merge, gh repo sync,
  запись релизов или запуск workflow.
- Не добавлять Co-Authored-By и упоминания генерации в коммиты/PR.
- Не обходить проверки. Исключение: pre-commit на прежнем техническом долге можно обойти
  через --no-verify, записав конкретный обход и причину в changelog.

## Работа с кодом

- До объяснения сбоя выполнить воспроизводящую его команду и показать результат.
  Исправлять реализацию, не подгонять тесты. Если исправление выходит за план — остановиться.
- Временные журналы помечать [DEBUG-<hex4>] и удалять перед завершением.
- Сначала искать существующее решение. Сохранять стиль проекта; не вводить классы и слои
  там, где достаточно функции. Комментарии объясняют причину, а не очевидное действие.
- Не выдумывать URL, библиотеки и API. Использовать read для чтения, edit для точечных
  изменений, write для новых файлов или полного переписывания.
- Не использовать curl/wget/ssh для внешних запросов; локальную доступность проверять lcurl.
  Внешний запрос предложить выполнить пользователю. Правила инструментов не являются изоляцией ОС.

## Контекст и хост

- При CONTEXT_WARN завершить текущую небольшую работу и предложить /cut;
  при CONTEXT_CUT не начинать большую работу. Передача хранится в vault, не заменяет route.
- Хост без подключённого события сжатия (сейчас Codex): обновлять передачу после каждого шага
  плана; при старте сессии прочитать `devflow handoff latest --fresh-minutes 30 --task <slug>`.
- Claude Code запускает фазовые роли через Agent; pi — через devflow phase run.
  Pi никогда не вызывает claude или claude-bridge; прямой провайдер anthropic/* разрешён.
- Модели фаз определяет глобальная model-policy.json; явный --model имеет приоритет.
  Не менять глобальную политику ради разового запуска.
- Перед реализацией интеграции читать полную относящуюся к ней документацию и примеры.
